# VS2026Handbook_Chapter6

A Python chapter project for the VS2026 handbook.

## Project Overview

This repository contains a collection of Python examples covering practical programming topics, including booking, discounts, invoices, pricing, products, and office expenses.

## Repository Contents

- `VS2026Handbook_Chapter6.py` — primary Python program
- `main.py` — application entry point
- `booking.py` — booking-related functionality
- `discount.py` — discount calculations
- `invoice_functions.py` — invoice utilities
- `items.py` — item data and helpers
- `models.py` — data models
- `office_expense.py` — office expense calculations
- `pricing.py` — pricing logic
- `products.py` — product definitions

## Requirements

- Python 3
- Visual Studio 2026 or another Python-compatible editor

## Running the Project

Open `VS2026Handbook_Chapter6.slnx` in Visual Studio 2026, or run the Python entry point from a terminal:

```bash
python main.py
```
